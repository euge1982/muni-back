## NUESTRO PROYECTO:

BACKEND DE PAGINA WEB Y APP MUNICIPAL PARA GESTION DE CURSOS, TALLERES Y ENCUENTROS, CON TOMA DE ASISTENCIA POR GEOLOCALIZACION

## DESCRIPCION

ESTE BACKEND ESTA DESARROLLADO EN EL FRAMEWORK NEST.JS CON TYPESCRIPT + MICROSERVICIOS + PRISMA + POSTGRESQL 

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

```
